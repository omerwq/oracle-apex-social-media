# Oracle APEX Social Media App (V1.0)

A simple Social Media application built using **Oracle APEX** as part of my learning journey with Oracle Live Labs.

## 🚀 Features
- Create, Read, and Delete Posts.
- Upload images (using BLOB columns).
- Geolocation support (Latitude/Longitude).
- Basic Reactions (Likes) system.
- Audit columns (Created/Updated by and date) using Database Triggers.
- **Custom UI enhancements using CSS.**
- **Client-side interactivity using JavaScript (e.g., Dynamic Actions, custom JS).**

## 🛠️ Technologies Used
- Oracle APEX
- Oracle Database
- SQL & PL/SQL
- Quick SQL (for generating the initial schema)
- **CSS3** (for custom styling)
- **JavaScript / jQuery** (for custom client-side logic)

## 📂 Project Structure
- `/db`: Contains the SQL scripts to create the tables and triggers.
- `/apex`: Contains the exported APEX application file.
- `/screenshots`: Application screenshots.
